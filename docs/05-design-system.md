# Design System

O design system deve fazer o produto parecer um aplicativo esportivo profissional.

As principais referencias visuais sao:

- Sofascore
- FotMob
- OneFootball
- Flashscore

## Nao Utilizar

A interface nao deve parecer:

- ERP
- CRM
- Dashboard SaaS
- Template generico de IA
- Painel administrativo

## Tipografia

A tipografia oficial e:

- Manrope

## Diretrizes Visuais

Priorizar:

- Mobile First
- Hierarquia tipografica forte
- Numeros grandes
- Estatisticas em destaque
- Proximos eventos em destaque
- Rankings visiveis
- Listas densas
- Secoes com divisores claros
- Conteudo direto

Evitar:

- Excesso de cards
- Excesso de sombras
- Bordas muito arredondadas
- Layout com aparencia corporativa
- Grandes areas vazias
- Componentes genericos com aparencia padrao de biblioteca

## Layout

O layout deve se aproximar de aplicativos esportivos:

- Match center
- Lista de partidas
- Placar em destaque
- Tabelas e rankings
- Abas horizontais
- Feed de eventos
- Densidade informacional

## Componentes

Componentes devem ter aparencia propria do produto.

Componentes de biblioteca, como shadcn/ui, podem ser usados como base estrutural, mas devem ser customizados para nao parecerem padrao.

## Dark Mode

Dark Mode deve ser considerado desde o inicio.

As variaveis de tema devem permitir alternancia futura sem reescrever componentes.
